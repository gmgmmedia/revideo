# Revideo Workspace

A monorepo for generating automated short-form video content using [Revideo](https://revideo.dev/).

## Project Structure

```
/revideo/
├── agents/                    # Generic agent templates (brand-agnostic)
│   ├── brand-extractor.md     # Extract brand identity from URLs/images
│   ├── code-generator.md      # Generate Revideo TSX scenes
│   └── sound-designer.md      # Create ElevenLabs SFX prompts
│
├── docs/
│   └── technical-reference.md # Revideo API documentation
│
├── scripts/
│   └── generate_sfx.py        # Generate SFX using ElevenLabs API
│
├── projects/
│   ├── raiku/                 # Raiku brand project
│   │   ├── brand-identity.json
│   │   ├── code-generator.md  # Raiku-specific agent (extends generic)
│   │   ├── sfx-plan.json      # SFX plan from sound-designer
│   │   ├── sfx-manifest.json  # Generated by generate_sfx.py
│   │   ├── sfx/{scene}/*.mp3  # ElevenLabs-generated audio
│   │   └── src/...
│   │
│   └── realmotion/            # RealMotion brand project
│       ├── brand-identity.json
│       ├── code-generator.md  # RealMotion-specific agent
│       └── src/...
│
└── node_modules/              # Single hoisted node_modules (npm workspaces)
```

## Automation Workflow

### 1. Brand Identity Extraction

Use `agents/brand-extractor.md` to generate a brand identity JSON from:
- Company website URL
- Screenshots/images
- Existing brand assets

Output: `projects/{brand}/brand-identity.json`

### 2. Video Code Generation

Each project has a brand-specific `code-generator.md` that:
1. References `agents/code-generator.md` for the generic workflow
2. Loads brand colors/styles from local `brand-identity.json`
3. Uses brand constants from `src/lib/brand.ts`

Workflow:
1. Read `docs/technical-reference.md` first
2. Read project's `brand-identity.json`
3. Parse user's timestamp script (VO + visual directions)
4. Generate TSX scene files with visual beats every 0.3s
5. Output to `src/scenes/`

### 3. Sound Design (Closed-Loop SFX Pipeline)

Sound design is fully integrated with code generation via two JSON contracts:

1. **`agents/sound-designer.md`** reads `projects/{brand}/brand-identity.json` (specifically `motion_design.sound_aesthetic_hint`, `energy_curve`, `pace.beat_density`) and outputs `projects/{brand}/sfx-plan.json` — a nested-by-scene structured plan.

2. **`scripts/generate_sfx.py --project {brand}`** reads `sfx-plan.json`, generates MP3s via ElevenLabs API into `projects/{brand}/sfx/{scene}/{id}_{name}.mp3`, and writes `projects/{brand}/sfx-manifest.json` (with file paths and computed `start_offset_seconds`). Also emits optional `timeline.xml` (FCPXML for CapCut) and `sfx_reference.csv`.

3. **`agents/code-generator.md`** auto-detects `sfx-manifest.json` at scene-generation time and wires `<Audio>` components into each scene's JSX. Falls back gracefully (no audio) when the manifest is absent.

### Schemas
- `sfx-plan.json` schema: see `agents/sound-designer.md` → "Output Schema"
- `sfx-manifest.json` schema: produced by `generate_revideo_manifest()` in `scripts/generate_sfx.py`
- Both use `"schema_version": "1.0"` for forward compatibility

### Volume defaults (when omitted in plan)
foreground=0.8 · accent=0.7 · background=0.3 · ambient=0.4

## Adding a New Brand Project

1. Create `projects/{brand}/` directory
2. Copy `package.json` and `tsconfig.json` from existing project
3. Update package name to `@revideo-workspace/{brand}`
4. Run brand-extractor agent → save to `brand-identity.json`
5. Create `src/lib/brand.ts` with brand constants
6. Create `code-generator.md` that references generic agent + brand specifics
7. Run `npm install` from root

## Pipeline Contracts

The generic agent system enforces three machine-checkable contracts:

### Contract 1: `brand-identity.json → motion_design` block

- **Producer**: `agents/brand-extractor.md` (Step 11C)
- **Consumers**: `agents/code-generator.md` (Step 1), `agents/sound-designer.md` (Step 0)
- **Schema location**: `agents/brand-extractor.md` → "OUTPUT JSON SCHEMA"
- **Fallback**: code-generator uses "Generic Professional" profile (easeOutCubic, 0.3s beats, fade transitions, no camera). sound-designer defaults to Minimal & Subtle style.

### Contract 2: `sfx-plan.json → sfx-manifest.json`

- **Producer of plan**: `agents/sound-designer.md`
- **Consumer of plan / Producer of manifest**: `scripts/generate_sfx.py`
- **Consumer of manifest**: `agents/code-generator.md` (Wiring SFX section)
- **Schema location**: `agents/sound-designer.md` → "Output Schema: sfx-plan.json"
- **Version field**: both files include `"schema_version": "1.0"` — script warns and falls back on mismatch
- **Fallback**: if manifest is missing, scene generates without `<Audio>` components (silent video)

### Contract 3: Scene-to-Scene Matched Cuts via `useScene().variables`

- **Producer**: scene N (writes closing transform at end)
- **Consumer**: scene N+1 (reads at start, animates from matched position)
- **Schema**: `{ anchor: string, position: Vector2, scale: number, rotation: number }` keyed under `'matchedCut'`
- **Usage rule**: only set when `brand-identity.json → motion_design.transition_vocabulary.matched_cut_friendly == true`

## Important Notes

- Revideo uses `@revideo/core` and `@revideo/2d` (NOT `@motion-canvas/*`)
- `makeScene2D` requires a scene name: `makeScene2D('sceneName', function* (view) {...})`
- **Revideo does NOT ship a `Camera` component.** Virtual camera moves use a wrapper `<Layout>` with animated `position()`/`scale()`/`rotation()`. See `docs/technical-reference.md` Section 11.
- Visual beats should occur on the cadence specified by `motion_design.pace.average_beat_duration` (default 0.3s)
- Scene quality is measured by a weighted rubric (target ≥ 9.0) — see `agents/code-generator.md` → "Quality Iteration Loop"
- `motion_design` is REQUIRED in `brand-identity.json`. Missing it triggers the Generic Professional fallback.
- SFX wiring is AUTOMATIC when `sfx-manifest.json` exists. Manual `<Audio>` placement is also supported.
- Generic agents in `agents/` are the source of truth — edit them via system upgrades. Project-specific overrides go in `projects/{brand}/code-generator.md`.
- Scenes should be 800+ lines for sufficient visual density (when generated for short-form content)
- **v2**: Every new project ships with `src/lib/motion-helpers.ts` alongside `brand.ts`. 10 standardized helpers (`charStagger`, `multiLayerGlow`, `countUpMetric`, `emphasisPulse`, `rimLight`, `alignToBeat`, `asymmetricPosition`, `computeStagger`, `cinematicFade`, `breathHold`). Skeleton in `agents/code-generator.md` → "Motion Helper Library Convention".
- **v2**: Brand-identity.json now includes `animation_vocabulary` block (text_entrance, emphasis_technique, camera_beat_sync, color_transition, shape_language, lighting_style) — schema_version 1.1.
- **v2**: Quality rubric expanded to 17 dimensions, max score 18.0. Target ≥15.0 for "stunning."
